# Данышпан Даму бала — лендинг

Next.js 15 (App Router) · TypeScript · Tailwind CSS 4 · Lucide React

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # өндірістік жинақ
npm start
```

## Мазмұнды өзгерту

Барлық байланыс деректері — `src/config/site.ts`:

- `SITE` — атауы, телефон, Instagram, мекенжай, жұмыс уақыты және т.б.
- `DOCUMENTS_URL` — Google Drive папкасына сілтеме. Бос болса, «Құжаттар сілтемесі жақында қосылады.» хабарламасы көрсетіледі.
- `MAP_CONFIG` — картаны нақтылау: `city` (мысалы, `"Алматы"`) немесе `coordinates: { lat, lng }`.

## Суреттер (`public/images`)

| Файл | Қайда көрсетіледі |
| --- | --- |
| `main-page.jpg/.jpeg/.png/.webp` | Басты беттегі үлкен фото |
| `about.jpg/.jpeg/.png/.webp` | «Балабақша туралы» бөліміндегі арка фото |
| қалған кез келген `.jpg/.jpeg/.png/.webp` | Галерея (атауы бойынша сұрыпталады) |

`main-page` және `about` галереяда қайталанбайды. Суреттер жоқ болса, әдемі алмастырғыштар көрсетіледі.
Бет статикалық түрде жиналады, сондықтан жаңа суреттерді қосқаннан кейін `npm run build` қайта іске қосыңыз
(`npm run dev` режимінде бетті жаңарту жеткілікті).
